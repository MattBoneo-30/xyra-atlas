# Xyra Atlas

An interactive learning atlas for practical knowledge, human psychology, laws, entrepreneurship, savings, languages and more.

## Development

The app is being built with Next.js, React, TypeScript and Tailwind CSS for Vercel deployment. See the feature branch and pull requests for the first implementation.

## Product principles

- Modern, accessible, visual design across desktop and mobile
- Real lessons and quizzes, not decorative placeholder cards
- Saved progress and eventual offline PWA support
- Explain legal topics with clear jurisdiction and currency limitations
- Teach safety and critical awareness when examining harmful manipulation tactics

Development is ongoing; no production deployment is implied.
